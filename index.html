一词一境 · 隐私政策

生效日期：2026 年 11 月 4 日 · 适用于 Chrome / Edge 扩展「一词一境 - 懂上下文的 AI 英语翻译与学习」

当前版本采用「自带 API Key」模式：除了下文默认开启、可以随时关闭的「用量统计上传」，开发者不运营任何接收你数据的服务器，不收集、不出售、不分析你的数据。翻译所需的文字只会发送到你自己在设置页填写的大模型接口；其余数据都只保存在你的浏览器里。

会发送给大模型接口的内容

只有在你主动触发翻译时（双击、划词、Alt+单击、开启全页翻译、截图翻译，或访问你设为「总是翻译」的网站），扩展才会把下列内容发送到你配置的 OpenAI 兼容接口（默认阿里云百炼 https://dashscope.aliyuncs.com/compatible-mode/v1，可在设置页更换）：

内容用途
你选中的单词或段落翻译对象
所在句子，以及设置页「额外上下文」允许的前后文字判断文中含义
网页地址的前 120 个字符和网页标题判断领域（如医学、编程）以选择合适的释义
全页翻译时页面上可见的段落文字生成译文
截图翻译时从截图里识别出的英文文字（不含截图本身）生成译文
观看带英文字幕的视频（YouTube、TikTok 和其他网站）时的英文字幕文字与视频标题（开启双语字幕时按播放进度分段发送；点「视频总结」时发送整条字幕；TikTok 上还会按「提前翻译」设置的条数，提前发送后面几条视频开头的字幕，开着全页翻译时也包括简介，这些视频你可能还没有看，设为 0 可关闭）生成双语字幕与视频总结
你在设置页填写的 API Key接口鉴权，仅随请求发送给该接口

这些请求由你使用的模型服务商处理，适用该服务商的隐私政策。扩展不会把内容发送给任何其他第三方。

截图只在本地处理：截图翻译时，扩展截取你框选的区域，用打包在扩展里的文字识别引擎（Tesseract）在你的浏览器里识别英文，截图不会上传到任何地方，识别完即丢弃；之后只有识别出的文字会按上表发送。

推荐链接

设置页推荐的模型厂家（如阿里云百炼、七牛云）的注册引导里，以及额度用完时提示里推荐的套餐，标有「推荐链接」的地址带有我们在该厂家推广计划里的推广码（如阿里云「云大使」）。只有在你点击时，浏览器才会打开该地址；推广关系由厂家根据这次访问记录，扩展不会写入 Cookie、不会改动你浏览的网页里的链接，也不会向我们发送任何信息。通过推荐链接注册或购买，我们会获得该厂家的推广佣金，你的价格不变。

点推荐按钮后，浏览器侧边栏会显示接入引导。引导第一步要判断你是否已经登录阿里云：扩展只在引导打开的那个阿里云页面里，调用阿里云页面自己用来显示顶栏账号状态的接口，只取「是否已登录」这一项，不读取账号信息；同时查看这个页面的地址是否进入了阿里云控制台。这些信息不保存、不发送给我们。你在引导里粘贴的 API Key 与在设置页填写的一样，只保存在本地并用于向该厂家的接口鉴权。

推荐配置的更新

设置页推荐的模型厂家、接入引导的步骤、推荐产品、说明文字，以及扩展里显示的联系邮箱来自一份配置文件。为了不用每次发布新版本就能更新这些内容，扩展会在浏览器启动时和之后每小时，从 cdn.jsdelivr.net、fastly.jsdelivr.net 或 chilisauce1212.github.io 下载这份公开文件（与本隐私政策放在同一个仓库）。这只是下载：请求不带 Cookie，也不附带你的任何数据，和打开一个公开网页一样（这些网站会像所有网站一样看到你的 IP 地址）。这份文件只含文字和链接，不含可执行的代码；扩展会逐项检查，格式不对就继续使用上次下载的版本。其中标有「广告」的厂家或产品是付费展示的。

用量统计上传（默认开启，可随时关闭）

这项上传默认开启。安装后第一次打开扩展弹窗时，弹窗顶部会说明上传什么，并提供「关闭上传」按钮；在你看到这条说明之前，扩展不会上传任何内容。你也可以随时在设置页「用量统计」里关掉「把用量统计上传给我们」。开着时，扩展大约每天一次，把按天汇总的数字发送到我们的服务器：每天用了哪个模型（你填写的模型名）、哪项功能（查词、全页翻译、字幕等），各用了多少 token、请求了多少次；同时附带扩展版本和一个第一次上传时随机生成的安装 ID（用来区分不同安装、统计有多少人在用，不包含也不关联你的姓名、邮箱或账号）。第一次上传会带上最近 30 天的统计。不上传接口地址、接口域名和 API Key。

不上传你查的单词和句子、网页地址和内容、生词本、API Key。我们用这些数字了解大家怎么使用、该优化哪些功能和推荐哪些模型，汇总后的数字（如总用户数、各模型的用量）可能会对外介绍；不用于广告，不出售，不向任何第三方提供单个安装的数据。服务器在中国大陆，不记录访问日志和你的 IP 地址（网络连接本身会让服务器看到 IP，但不保存）；你随时可以关掉开关，关掉后扩展不再上传；已经上传的汇总数字会保留，直到我们停止这项统计。如果你希望删除已上传的数据，在设置页「用量统计」→「会上传什么？会不会泄露隐私？」里点「发邮件给我们」，邮件会自动带上你的安装 ID；也可以自己发邮件到 info@onecontext.cloud 并附上安装 ID。我们会删除这个安装 ID 的全部数据。

PDF

网页里的 PDF 改用扩展自带的阅读页打开时，扩展在你的浏览器里直接下载这个 PDF 文件并显示，文件不会上传到任何地方；查词、划选翻译时发送的内容与在网页上相同（所选文字及所在句子、PDF 的网址与标题）。本地 PDF 只在你的电脑上打开。

问题反馈

只有你在查词浮层或扩展弹窗里点「反馈问题」时，扩展才会整理一份诊断信息：当前网址和标题、出问题位置附近的页面结构片段（已去掉脚本、表单里填写的内容、可编辑区域的文字和网址参数）、浮层里显示的内容、扩展与浏览器版本、设置摘要（不含 API Key 和自定义语境，接口地址只保留域名）、本次打开浏览器以来的报错，以及一张当时可见区域的截图。

这些信息先在反馈页完整展示给你，每一部分都可以取消勾选，截图默认不附带。扩展不会自动发送：由你选择用自己的邮件程序发给我们，或复制、下载后自行发送。收到的反馈只用于排查和修复问题。

保存在你浏览器里的数据

  • 设置（接口地址、模型名称等）：保存在 chrome.storage.local。API Key 加密后单独保存在扩展自己的 IndexedDB 中，只有扩展后台能读取，网页和网页里的扩展脚本都拿不到。
  • 生词本：你加入的单词、释义、例句和复习记录，保存在扩展自己的 IndexedDB 中。
  • 翻译缓存：最多约 20000 条，保存在扩展自己的 IndexedDB 中，用于减少重复请求；设置页可一键清除。这个标签页翻过的视频字幕另存一份，刷新页面后直接恢复，关闭标签页或浏览器时删除。
  • 模型测试结果：你点「测试全部模型」时，扩展用你的 API Key 向你填写的接口给每个模型发一句很短的请求，哪些模型能用的结果保存在本地。
  • 全页翻译状态：哪些标签页、哪些网站要保持全页翻译。
  • 用量统计：你用自己的 API Key 消耗了多少 token（按模型、功能、日期汇总的数字，不含任何查询内容），用于设置页「用量统计」；没有关闭上传时，按天汇总的数字会按上面「用量统计上传」说的发送给我们。
  • 最近的报错：最多 30 条（时间、出错的功能、原因、网页地址的路径部分），只在问题反馈时由你决定是否附带；关闭浏览器即清空。

除上面说的用量统计上传外，这些数据不会离开你的设备，卸载扩展时由浏览器一并删除。

不做的事

  • 不收集浏览记录；除上述翻译场景和你主动发起的问题反馈外，不上传网页内容。
  • 不使用任何第三方统计、广告或追踪代码；唯一的统计是上面说的、可以随时关闭的用量统计上传，发往我们自己的服务器。
  • 不出售、不转让数据，也不将数据用于与翻译无关的目的。

权限说明

  • storage：保存设置、生词本和全页翻译状态。
  • 访问所有网站：在你浏览的任意英文网页上提供划词翻译、全页翻译和截图翻译（截取当前标签页的可见区域也依赖这项权限）。只在上述翻译场景下发送网页文字。
  • offscreen：截图翻译时打开一个不可见的扩展页面，在本地运行文字识别引擎；闲置两分钟后自动关闭。
  • alarms：复习提醒。每 30 分钟在本地检查一次生词本里有没有该复习的词，有就在扩展图标上显示小红点；不联网、不上传数据。另外每小时下载一次上面「推荐配置的更新」里说的公开配置文件；用量统计上传开着时，也用它大约每天上传一次。

朗读

单词发音使用浏览器自带的语音合成（Web Speech API）。部分系统语音可能由浏览器或操作系统提供商在线合成，适用其各自的隐私政策。

政策变更与联系方式

如本政策有变更，会更新本页面并修改生效日期。若今后推出由我们提供的翻译服务（如免费额度、按量付费），会在上线前更新本政策，写明经由我们服务器传输的数据、保存期限与用途，并在扩展内提示；届时你仍可选择继续使用自己的 API Key。

有任何问题，或要求删除已上传的用量数据，请联系：info@onecontext.cloud

Privacy Policy (English)

Effective date: November 4, 2026 · Applies to the Chrome / Edge extension "一词一境 (Yi Ci Yi Jing) – context-aware AI English translation and learning". If the Chinese and English versions differ, the Chinese version above prevails.

In its current "bring your own API key" mode, apart from the usage statistics upload described below (on by default, can be turned off at any time), the developer does not run any server that receives your data, and does not collect, sell or analyze your data. Text needed for translation is sent only to the AI model API that you configure in Settings; everything else stays in your browser.

What is sent to the AI model API

Only when you trigger a translation (double-click, select text, Alt+click, turn on full-page translation, screenshot translation, or visit a site you set to "always translate") does the extension send the following to the OpenAI-compatible API you configured (by default Alibaba Cloud Model Studio, https://dashscope.aliyuncs.com/compatible-mode/v1; you can change it in Settings):

Screenshots stay on your device. For screenshot translation the extension captures the area you select and recognizes the English text in your browser with the bundled OCR engine (Tesseract). The screenshot is never uploaded and is discarded after recognition; only the recognized text is sent as described above.

Referral links

In the sign-up guides for the model providers recommended in Settings (such as Alibaba Cloud Model Studio and Qiniu Cloud), and in the plans suggested when your quota runs out, links marked "推荐链接" (referral link) carry our referral code for that provider's affiliate program (such as Alibaba Cloud's "云大使"). The browser opens such a link only when you click it; the provider records the referral from that visit. The extension does not set cookies, does not change links on the pages you browse and sends nothing to us. If you sign up or buy through a referral link we receive a commission from that provider; your price is unchanged.

After you click a referral button, a setup guide opens in the browser side panel. To tell whether you are signed in to Alibaba Cloud, the extension calls, only in the Alibaba Cloud page the guide opened, the endpoint that page itself uses to show the account status in its top bar, and reads only whether you are signed in, not your account details; it also checks whether that page's address has reached the Alibaba Cloud console. This is neither stored nor sent to us. An API key you paste in the guide is treated like one entered in Settings: stored locally and used only to authenticate with that provider.

Configuration updates

The recommended providers, guide steps, recommended products, texts and the contact email address in the extension come from a configuration file, so they can be updated without releasing a new version. At browser startup and every hour after that, the extension downloads this public file from cdn.jsdelivr.net, fastly.jsdelivr.net or chilisauce1212.github.io (it lives in the same repository as this policy). This is a download only: the request carries no cookies and none of your data, just like opening a public web page (like every website, these sites can see your IP address). The file contains only text and links, never executable code; the extension checks every field and keeps the previous version if anything is malformed. Providers or products marked "广告" (ad) are paid placements.

Usage statistics upload (on by default, can be turned off at any time)

This upload is on by default. The first time you open the extension popup after installing, a notice at the top explains what is uploaded and offers a "关闭上传" (turn off upload) button; nothing is uploaded before you have seen that notice. You can also turn off "把用量统计上传给我们" at any time on the Usage page in Settings. While it is on, about once a day the extension sends daily totals to our server: which model you used (the model name you entered), which feature (word lookup, full-page translation, subtitles, etc.), and how many tokens and requests each used. It also sends the extension version and an install ID generated at random on the first upload (used to tell installs apart and count how many people use the extension; it does not contain or link to your name, email or account). The first upload includes the last 30 days.

It never uploads the words or sentences you look up, page addresses or content, your vocabulary list, your API key, or your API address or its domain. We use these figures to understand how the extension is used, which features to improve and which models to recommend. Aggregated figures (such as total users or usage per model) may be shared publicly; they are not used for advertising or sold, and data for an individual install is never provided to any third party. The server is in mainland China and keeps no access logs and no IP addresses (the network connection itself reveals your IP to the server, but it is not stored). Turning the upload off stops further uploads; figures already uploaded are kept until we end this program. To have uploaded data deleted, click "发邮件给我们" (email us) under "会上传什么？会不会泄露隐私？" on the Usage page, which fills in your install ID, or email info@onecontext.cloud with your install ID. We will delete all data for that install ID.

PDF

When a PDF on the web opens in the extension's own viewer, the extension downloads the file in your browser and displays it; the file is not uploaded anywhere. Word lookups and translations send the same content as on web pages (the selected text and its sentence, the PDF's address and title). Local PDFs are opened only on your computer.

Feedback

Only when you click "反馈问题" (report a problem) in the lookup popup or the extension popup does the extension prepare diagnostic information: the current page address and title, a structural snippet of the page around the problem (with scripts, form input, editable text and URL parameters removed), what the popup showed, extension and browser versions, a settings summary (without the API key or custom context; only the domain of the API address), errors since the browser was opened, and a screenshot of the visible area.

All of this is shown to you in full on the feedback page first; every part can be unchecked, and the screenshot is not included by default. Nothing is sent automatically: you choose to send it with your own email program, or copy or download it and send it yourself. Feedback is used only to investigate and fix problems.

Data stored in your browser

  • Settings (API address, model name, etc.): stored in chrome.storage.local. The API key is encrypted and stored separately in the extension's own IndexedDB; only the extension's background service can read it, and neither web pages nor the extension's scripts running in web pages can access it.
  • Vocabulary list: the words, meanings, example sentences and review history you add, stored in the extension's own IndexedDB.
  • Translation cache: up to about 20,000 entries in the extension's own IndexedDB to avoid repeated requests; can be cleared in Settings. Video subtitles translated in a tab are kept separately so they come back after a page refresh, and are deleted when the tab or browser is closed.
  • Model test results: when you click "测试全部模型" (test all models), the extension sends one very short request per model to the API you configured, with your API key, and stores locally which models work.
  • Full-page translation state: which tabs and sites keep full-page translation on.
  • Usage statistics: how many tokens your own API key used (totals by model, feature and date, with no query content), shown on the Usage page in Settings; unless you turn the upload off, the daily totals are sent to us as described above.
  • Recent errors: up to 30 entries (time, feature, reason, path part of the page address), attached to feedback only if you choose; cleared when the browser closes.

Apart from the usage statistics upload above, this data does not leave your device and is removed by the browser when you uninstall the extension.

What we don't do

  • We don't collect browsing history, and don't upload page content except in the translation cases above and feedback you choose to send.
  • We don't use any third-party analytics, advertising or tracking code; the only statistics are the usage statistics upload above, which you can turn off, sent to our own server.
  • We don't sell or transfer data, or use it for purposes unrelated to translation.

Permissions

  • storage: saves settings, the vocabulary list and full-page translation state.
  • Access to all sites: provides word lookup, full-page translation and screenshot translation on any English page you visit (capturing the visible area of the current tab also relies on this). Page text is sent only in the translation cases above.
  • offscreen: for screenshot translation, opens an invisible extension page that runs the OCR engine locally; it closes after two minutes of inactivity.
  • alarms: review reminders. Every 30 minutes the extension checks locally whether any words are due for review and, if so, shows a small red dot on its icon; this uses no network and uploads nothing. It also downloads the public configuration file described above every hour, and, while the usage statistics upload is on, uploads about once a day.

Pronunciation

Word pronunciation uses the browser's built-in speech synthesis (Web Speech API). Some system voices may be synthesized online by the browser or operating system vendor, under their own privacy policies.
