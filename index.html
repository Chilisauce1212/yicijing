一词一境 · 隐私政策

生效日期：2026 年 10 月 23 日 · 适用于 Chrome / Edge 扩展「一词一境 - 懂上下文的 AI 英语翻译与学习」

当前版本采用「自带 API Key」模式：开发者不运营任何接收你数据的服务器，不收集、不出售、不分析你的数据。翻译所需的文字只会发送到你自己在设置页填写的大模型接口；其余数据都只保存在你的浏览器里。

会发送给大模型接口的内容

只有在你主动触发翻译时（双击、划词、Alt+单击、开启全页翻译、截图翻译，或访问你设为「总是翻译」的网站），扩展才会把下列内容发送到你配置的 OpenAI 兼容接口（默认阿里云百炼 https://dashscope.aliyuncs.com/compatible-mode/v1，可在设置页更换）：

内容用途
你选中的单词或段落翻译对象
所在句子，以及设置页「额外上下文」允许的前后文字判断文中含义
网页地址的前 120 个字符和网页标题判断领域（如医学、编程）以选择合适的释义
全页翻译时页面上可见的段落文字生成译文
截图翻译时从截图里识别出的英文文字（不含截图本身）生成译文
观看 YouTube 视频时的英文字幕文字与视频标题（开启双语字幕时按播放进度分段发送；点「视频总结」时发送整条字幕）生成双语字幕与视频总结
你在设置页填写的 API Key接口鉴权，仅随请求发送给该接口

这些请求由你使用的模型服务商处理，适用该服务商的隐私政策。扩展不会把内容发送给任何其他第三方。

截图只在本地处理：截图翻译时，扩展截取你框选的区域，用打包在扩展里的文字识别引擎（Tesseract）在你的浏览器里识别英文，截图不会上传到任何地方，识别完即丢弃；之后只有识别出的文字会按上表发送。

推荐链接

设置页推荐的模型厂家（如阿里云百炼、七牛云）的注册引导里，以及额度用完时提示里推荐的套餐，标有「推荐链接」的地址带有我们在该厂家推广计划里的推广码（如阿里云「云大使」）。只有在你点击时，浏览器才会打开该地址；推广关系由厂家根据这次访问记录，扩展不会写入 Cookie、不会改动你浏览的网页里的链接，也不会向我们发送任何信息。通过推荐链接注册或购买，我们会获得该厂家的推广佣金，你的价格不变。

点推荐按钮后，浏览器侧边栏会显示接入引导。引导第一步要判断你是否已经登录阿里云：扩展只在引导打开的那个阿里云页面里，调用阿里云页面自己用来显示顶栏账号状态的接口，只取「是否已登录」这一项，不读取账号信息；同时查看这个页面的地址是否进入了阿里云控制台。这些信息不保存、不发送给我们。你在引导里粘贴的 API Key 与在设置页填写的一样，只保存在本地并用于向该厂家的接口鉴权。

推荐配置的更新

设置页推荐的模型厂家、接入引导的步骤、推荐产品和说明文字来自一份配置文件。为了不用每次发布新版本就能更新这些内容，扩展会在浏览器启动时和之后每小时，从 cdn.jsdelivr.net、fastly.jsdelivr.net 或 chilisauce1212.github.io 下载这份公开文件（与本隐私政策放在同一个仓库）。这只是下载：请求不带 Cookie，也不附带你的任何数据，和打开一个公开网页一样（这些网站会像所有网站一样看到你的 IP 地址）。这份文件只含文字和链接，不含可执行的代码；扩展会逐项检查，格式不对就继续使用上次下载的版本。其中标有「广告」的厂家或产品是付费展示的。

PDF

网页里的 PDF 改用扩展自带的阅读页打开时，扩展在你的浏览器里直接下载这个 PDF 文件并显示，文件不会上传到任何地方；查词、划选翻译时发送的内容与在网页上相同（所选文字及所在句子、PDF 的网址与标题）。本地 PDF 只在你的电脑上打开。

问题反馈

只有你在查词浮层或扩展弹窗里点「反馈问题」时，扩展才会整理一份诊断信息：当前网址和标题、出问题位置附近的页面结构片段（已去掉脚本、表单里填写的内容、可编辑区域的文字和网址参数）、浮层里显示的内容、扩展与浏览器版本、设置摘要（不含 API Key 和自定义语境，接口地址只保留域名）、本次打开浏览器以来的报错，以及一张当时可见区域的截图。

这些信息先在反馈页完整展示给你，每一部分都可以取消勾选，截图默认不附带。扩展不会自动发送：由你选择用自己的邮件程序发给我们，或复制、下载后自行发送。收到的反馈只用于排查和修复问题。

保存在你浏览器里的数据

  • 设置（含接口地址、模型名称和 API Key）：保存在 chrome.storage.local。
  • 生词本：你加入的单词、释义和例句，保存在 chrome.storage.local。
  • 翻译缓存：最多约 20000 条，保存在扩展自己的 IndexedDB 中，用于减少重复请求；设置页可一键清除。
  • 全页翻译状态：哪些标签页、哪些网站要保持全页翻译。
  • 用量统计：你用自己的 API Key 消耗了多少 token（按模型、功能、日期汇总的数字，不含任何查询内容），用于设置页「用量统计」。
  • 最近的报错：最多 30 条（时间、出错的功能、原因、网页地址的路径部分），只在问题反馈时由你决定是否附带；关闭浏览器即清空。

这些数据不会离开你的设备，卸载扩展时由浏览器一并删除。

不做的事

  • 不收集浏览记录；除上述翻译场景和你主动发起的问题反馈外，不上传网页内容。
  • 不使用任何统计、广告或追踪代码。
  • 不出售、不转让数据，也不将数据用于与翻译无关的目的。

权限说明

  • storage：保存设置、生词本和全页翻译状态。
  • 访问所有网站：在你浏览的任意英文网页上提供划词翻译、全页翻译和截图翻译（截取当前标签页的可见区域也依赖这项权限）。只在上述翻译场景下发送网页文字。
  • offscreen：截图翻译时打开一个不可见的扩展页面，在本地运行文字识别引擎；闲置两分钟后自动关闭。
  • alarms：复习提醒。每 30 分钟在本地检查一次生词本里有没有该复习的词，有就在扩展图标上显示小红点；不联网、不上传数据。另外每小时下载一次上面「推荐配置的更新」里说的公开配置文件。

朗读

单词发音使用浏览器自带的语音合成（Web Speech API）。部分系统语音可能由浏览器或操作系统提供商在线合成，适用其各自的隐私政策。

政策变更与联系方式

如本政策有变更，会更新本页面并修改生效日期。若今后推出由我们提供的翻译服务（如免费额度、按量付费），会在上线前更新本政策，写明经由我们服务器传输的数据、保存期限与用途，并在扩展内提示；届时你仍可选择继续使用自己的 API Key。

Privacy Policy (English summary)

In its current bring-your-own-key mode, Yi Ci Yi Jing does not operate any server that receives your data, and does not collect, sell or analyze your data. When you trigger a translation, the selected text, its surrounding sentence (plus any extra context you enable), the first 120 characters of the page URL and the page title are sent only to the OpenAI-compatible API endpoint you configure in Settings, together with your own API key. For screenshot translation, the captured region is recognized locally in your browser by the bundled Tesseract OCR engine and is never uploaded; only the recognized English text is sent. On YouTube, the English caption text and video title are sent to generate bilingual subtitles and, when you ask for it, a video summary. Settings, your vocabulary list and the translation cache are stored locally in your browser and are removed when you uninstall the extension. No analytics, ads or tracking are used. Referral links: in the sign-up guides for the recommended model providers in Settings (such as Alibaba Cloud Model Studio and Qiniu Cloud), and in the plans suggested when your quota runs out, links marked "推荐链接" carry our affiliate code for that provider. They open only when you click them; the extension sets no cookies, does not change links on the pages you visit and sends nothing to us. If you sign up or buy through them we receive a commission from that provider; your price is unchanged. Recommended providers, guide steps and offers come from a public configuration file that the extension downloads from cdn.jsdelivr.net, fastly.jsdelivr.net or chilisauce1212.github.io at browser startup and every hour; the request carries no cookies or user data, the file contains only text and links (no code), and entries marked "广告" are paid placements.
